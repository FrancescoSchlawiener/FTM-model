1) A gegen B für die Milchstraße
   A: r0 = GM/(3 v0²)       = 1.778 kpc   (v0 = 220 km/s, M = 6e10 M☉)
   B: r0 = (1/3)·sqrt(GM/a0) = 2.783 kpc
   Identität: setzt man v0⁴ = G·M·a0 ein, wird A zu B:
      v0 aus v⁴ = GMa0 bei M = 6e10 M☉: 175.8 km/s  ->  A = 2.783 kpc = B
      M aus v⁴ = GMa0 bei v0 = 220 km/s: 1.471e+11 M☉  ->  B = 4.357 kpc = A (mit dieser Masse)
   -> A und B sind dieselbe Formel r0 = r*/3 = GM/(3 v_flach²). Der Unterschied liegt nur im Datenpaar (M, v0).

2) r0 aus Naturkonstanten und Torus-Atmen: r0 = r*/3 = (1/3)·sqrt(6π·Δs·R_H),  a0 = c²/(2π R_H) = c·H0/2π
   R_H = c/H0 = 4282.7 Mpc,  c²/(2π R_H) = 1.0824e-10 m/s²
   M = 1.00e+09 M☉   Δs = 4.923e+11 m   r0 =  0.378 kpc   v_flach =   61.6 km/s
   M = 1.00e+10 M☉   Δs = 4.923e+12 m   r0 =  1.196 kpc   v_flach =  109.5 km/s
   M = 6.00e+10 M☉   Δs = 2.954e+13 m   r0 =  2.930 kpc   v_flach =  171.4 km/s
   M = 1.47e+11 M☉   Δs = 7.237e+13 m   r0 =  4.587 kpc   v_flach =  214.4 km/s
   M = 1.00e+12 M☉   Δs = 4.923e+14 m   r0 = 11.963 kpc   v_flach =  346.2 km/s

3) κ0 und λ: stationäres Feldgedächtnis g = g_N + ∫κ0 e^{-λs} g ds  =>  g = g_N/(1 - κ0/λ)
   Vergleich mit g = g_N/(1-q):  κ0/λ = q(r) = exp(-r*/r)  (nur das Verhältnis ist festgelegt)
   Milchstraße r =  2.00 kpc   κ0/λ = q = 0.0154
   Milchstraße r =  5.00 kpc   κ0/λ = q = 0.1883
   Milchstraße r =  8.35 kpc   κ0/λ = q = 0.3679
   Milchstraße r = 20.00 kpc   κ0/λ = q = 0.6587
   Milchstraße r = 50.00 kpc   κ0/λ = q = 0.8462
   λ allein bestimmt nur die Nachlaufzeit 1/λ nach einer Änderung der Massenverteilung:
   λ = H0 (Atmen)         Nachlaufzeit 1/λ =   13.967 Mrd Jahre
   λ = 1/(100 Mio a)      Nachlaufzeit 1/λ =    0.100 Mrd Jahre
   λ = 1/(1 Mrd a)        Nachlaufzeit 1/λ =    1.000 Mrd Jahre
