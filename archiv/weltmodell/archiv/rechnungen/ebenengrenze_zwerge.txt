1   Formel und zweiter Weg
==============================================================================================================
   D·G'' = Γ·G, G(0) = 1, G beschränkt; unter ϖ = ℓ: D, darüber μD (Faltungen je Ebene additiv, D_Ebene = GM_Ebene/c), Γ gleich.
   Stetig: G und Fluss D·G′ (Schritte mit c). Unten G = A e^{−kϖ} + B e^{kϖ}, oben C e^{−kϖ/√μ}:
   B/A = R e^{−2kℓ}, R = (1 − √μ)/(1 + √μ);  q = G(L) = e^{−kL}(1 + R e^{−2k(ℓ−L)})/(1 + R e^{−2kℓ}),  k = s/L,  L = ϖ_R = r*
   Tiefe der Grenze: ℓ = d·(M/3M_p)^{1/3} (ℓ³ = GM/T, T = 3GM_p/d³, Elternmasse als Punkt). Mit s = r*/r (Punktmasse) ist kℓ = ℓ/r.
   Tief (s ≪ 1): ν_b/ν = (1 + R e^{−2ℓ/r})/(1 − R e^{−2ℓ/r});  R → −1: ν_b/ν → tanh(ℓ/r)

3   Schranken: unter Newton, über isoliert
==============================================================================================================
   G ist auf der ganzen Halbgeraden positiv (Γ > 0, Maximumprinzip), also 0 < q_b < 1 und ν_b > 1: nie unter Newton.
   Für μ ≥ 1 ist R ≤ 0 und q_b ≤ e^{−s}: ν_b ≤ ν, die Grenze hebt nie über den Wert ohne Grenze. Heben (R > 0) verlangte μ < 1.
   Gitter s = 10⁻³…30, ℓ/L = 1…100, μ = 1…10¹²: min ν_b = 1.000000 (> 1), max ν_b/ν = 1.000000 (≤ 1)
   Pal 14   : σ_N = 0.66, mit Grenze 1.78 (≥ σ_N), gemessen 0.38;  isoliert 2.06, Grenze allein 2.06
   NGC 2419 : σ_N = 5.09, mit Grenze 6.49 (≥ σ_N), gemessen 4.1;  isoliert 6.49, Grenze allein 6.49
   DF4      : σ_N = 7.15, mit Grenze 19.20 (≥ σ_N), gemessen 4.2;  isoliert 19.38, Grenze allein 19.36
