1 Umkehrbedingung auf dem flachen T³
====================================================================================================
Ω_m = 0.3134, Ω_r = 9.14e-05, Ω_s = (π²/45)Θ² = 0.2443 (Λ = 13.24 Gpc), übrige Ω_x = 0.4422
Jeder Summand ist ≥ 0: Ω_s ∝ Γ(4)Σ1/n⁴ > 0 (Zählung der Rückläufe), Materie und Strahlung ≥ 0, T³ ohne Krümmung.
⇒ E² > 0 für alle a: H wechselt das Vorzeichen nie. Numerisch, min E² über a ∈ [1, 10⁶]:
  Ω_x fest (w = −1)                min E² = 0.6865  → H∞ = 55.84 km/s/Mpc
  Ω_x ∝ a⁻³·⁽¹⁺ʷ⁾, w = −0,9        min E² = 0.2513  → H∞ = 33.79 km/s/Mpc
  Ω_x ∝ a⁻², Bindung eingefroren   min E² = 0.2443  → H∞ = 33.32 km/s/Mpc
  Ω_x = 0 ab heute                 min E² = 0.2443  → H∞ = 33.32 km/s/Mpc
Endrate bei festem Λ, Rest verklungen: H_s = H0·√Ω_s = 33.32 km/s/Mpc = π²c/(√45·Λ) = 33.32

Was eine Umkehr bräuchte: einen Summanden Ω_n < 0 mit |Ω_n(a)| = Ω_m a⁻³ + Ω_s bei endlichem a.
Bei festem Λ bleibt Ω_s; ein negativer Summand ∝ a^{−3(1+w_n)} holt ihn nur ein, wenn er wächst (w_n < −1).
  Ω_n = −0.01, w_n = -0.5: keine Umkehr (min E² = 0.244)
  Ω_n = −0.01, w_n = -1.0: keine Umkehr (min E² = 0.234)
  Ω_n = −0.01, w_n = -1.1: Umkehr bei a = 42413.1
Mit wachsendem Λ fällt Ω_s ∝ Λ⁻² gegen null, bleibt aber > 0: auch dann keine Umkehr, H → 0 von oben.
Das Modell hat keinen negativen Summanden: die Rückstellung σ = 0 ist das Bremsglied (w = 0, ≥ 0), der Vakuumteil > 0.

2 Λ fest oder wachsend: Endzustand, Kac-Maß, Rate
====================================================================================================
Horizontentropie zum Vakuumteil S_Λ = (45/π³)(Λ/ℓ_P)² = 9.272e+122 k  (Probe πc²/(ℓ_P²H_s²) = 9.272e+122)

Λ wächst mindestens mit ε = Λ̇/Λ = Ṡ_i/(2S_Λ) = 3.829e-37 s⁻¹ (1/ε = 8.28e+28 a) ⇒ dS_Λ/dt ≥ Ṡ_i:
  das Maß wächst mindestens so schnell wie Entropie entsteht; Kac greift nicht, der Zustand kehrt nicht zurück (Spirale),
  die Form kehrt zurück (flache Matrix → Wirbel → Faltung).
Mit Ṡ_i je Horizont fest: Λ² = Λ0² + (π³ℓ_P²Ṡ_i/45)·t ⇒ Λ ∝ t^½ spät, H_s ∝ 1/Λ; H_s halbiert sich nach 1.24e+29 a
  Rate: Ḣ_s/H_s = −ε,  q = −1 + ε/H_s = −1 + 3.55e-19;  w_s = −1 + (2/3)ε/H = −1 + 1.17e-19 (heute)
  ⇒ Λ fest: H → H_s = const (Endzustand, verletzt 04). Λ wächst: H → 0 asymptotisch, ohne Umkehr.
