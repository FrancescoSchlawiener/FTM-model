A1 Kontaktform mit Reeb-Feld ∂_t: explizite Konstruktion (sympy)
====================================================================================================
α = dt + e^{ϖ/ℓ}(cos kz dx + sin kz dy)   auf T³(x,y,z) × [0,Λ]∋ϖ × ℝ∋t
  α∧(dα)² ∝ k*exp(2*varpi/ell)/ell   (≠ 0 überall ⇒ Kontaktform)
  Reeb-Feld R = [1, 0, 0, 0, 0]   (= ∂_t: das Zeitfeld)
  ohne ϖ-Abhängigkeit (e^{ϖ/ℓ} → 1): α∧(dα)² = 0  ⇒ keine Kontaktform
  ϖ-unabhängig mit dϖ-Anteil f(x,y,z)dϖ: α∧(dα)² ∝ -k*(sin(k*z)*Derivative(f(x, y, z), y) + cos(k*z)*Derivative(f(x, y, z), x))
    = (rot β₃·∇f)-Anteil; ∫_{T³} dβ₃∧df = ∫ d(β₃∧df) = 0 ⇒ wechselt das Vorzeichen, Nullstelle auf T³.
  Satz (Stokes): Reeb = ∂_t mit α = dt + β (β zeitfrei, weil der Reeb-Fluss α erhält) verlangt dβ symplektisch
  auf dem Schnitt Σ⁴. Σ⁴ geschlossen (T³ × S¹) ⇒ ∫(dβ)² = ∫d(β∧dβ) = 0, Widerspruch. Mit innerer Richtung als
  Kreis S¹ gibt es keine Kontaktform mit Reeb-Feld u. Möglich nur mit Rand (ϖ ∈ [0,Λ]) UND ϖ-abhängigen Koeffizienten.
  Probe, 5 zufällige β auf T⁴ (Gitter 12⁴): Mittel von Pf(dβ) / min / max:

A2 Atmen im Kontaktbild: Reeb-Fluss oder nicht?
====================================================================================================
α = dt + a(t)·e^{ϖ/ℓ}(cos kz dx + sin kz dy)  (Atmen in α eingesetzt)
  Reeb-Feld: R_t = 1
             R_ϖ = -ell*Derivative(a(t), t)/a(t)
  ⇒ mit ȧ ≠ 0 ist ∂_t kein Reeb-Feld mehr (R erhält α: L_Rα = 0; Atmen ändert α). Atmen ist höchstens ein
    konformer Kontaktfluss L_Xα = fα; die Dehnung e^{ϖ/ℓ} läuft längs ϖ (Liouville-Richtung), nicht längs u.
  Metrische Lesart α = −u♭/c (g_tt = −c², g_ti = −c·β_i): i_u dα = Beschleunigung von u ⇒ Reeb ⇔ u geodätisch;
  dα|_{u⊥} = 2ω (Wirbel von u); Kontakt ⇔ Pf(ω) ≠ 0 im 4-dim. u⊥ = T³ × ϖ: u muss in zwei Ebenen drehen,
  eine davon mischt Raum und innere Richtung (Verwindung). Ein wirbelfreies, gleich atmendes u (u♭ = −c dt)
  gibt dα = 0: Frobenius-integrierbar, das Gegenteil von Kontakt.
  Der Reeb-Fluss trägt dα mit (L_R dα = 0): Koordinatenkomponenten fest ⇒ orthonormal ω_xy ∝ a⁻², ω_zϖ ∝ a⁻¹.
  Kontakt-Torsion τ = L_u g = 2H·h (Raum): das Atmen ist genau die Torsion; H(t) selbst legt α nicht fest.
