  Rueckverdichtung der Strahlung zu einer neuen Falte (zweiter Hauptsatz):
    N Falten der Masse M strahlen S_rad = N beta S0 ab (Energie N M c^2). Bis zur Rueckverdichtung wird die
    Strahlung um den Faktor z_f = a2/a1 rotverschoben (Energie / z_f, Entropie bleibt). Eine neue Falte aus
    dieser Energie hat S = (N/z_f)^2 S0. Erlaubt ist das nur, wenn (N/z_f)^2 S0 >= N beta S0, also
        N >= beta * z_f^2
    z_f = 1:  N >= 1.485
    z_f = 10:  N >= 148.5
    z_f = 1000:  N >= 1.485e+06
    -> Rueckverdichtung ist nur hierarchisch aufwaerts erlaubt (mehr Masse in weniger Falten). In einer
       Kontraktionsphase (z_f < 1, Blauverschiebung) wird sie leichter: das ist das Tolman-Problem zyklischer Modelle.

  Falte im geschlossenen Kasten (Hawking 1976): stabiles Gleichgewicht mit eigener Strahlung nur fuer E_rad < M c^2/4
    Sonne als Falte 1 M_S    V_max = 4.079e+90 m^3,  R_max = 9.912e+29 m  (R_obs = 4.4e+26 m)
    Sgr A* 4,15e6 M_S        V_max = 5.021e+123 m^3,  R_max = 1.062e+41 m  (R_obs = 4.4e+26 m)
    M87* 6,5e9 M_S           V_max = 4.733e+139 m^3,  R_max = 2.244e+46 m  (R_obs = 4.4e+26 m)
    -> Ohne Expansion (fester Kasten) stellt sich ein stationaeres Gleichgewicht Falte + Strahlung ein: das ist
       maximale Entropie, kein Kreislauf. Erst das Atmen (V waechst, T_aussen faellt) macht das Gleichgewicht
       instabil (negative Waermekapazitaet der Falte) und startet die Rueckgabe.
    Waermekapazitaet der Falte C = dE/dT = -8 pi G M^2 k/(hbar c) = -2.898e+54 J/K fuer 1 M_S  (negativ)

  Stationaritaet: dS_sys/dt = sigma - J = 0 und Senke mit Kapazitaet S_max = pi k c^2/(l_P^2 H^2)
    dauerhaft nur, wenn dS_max/dt >= sigma_ges   <=>   -dH/dt >= l_P^2 H^3 sigma_ges /(2 pi c^2 k)
